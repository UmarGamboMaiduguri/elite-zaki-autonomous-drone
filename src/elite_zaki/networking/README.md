# Elite Zaki Networking Engine

The Networking Engine provides the foundation for secure telemetry and communication research within Elite Zaki.

## Purpose

The networking layer is designed to explore how telemetry generated by an autonomous aerial system can be structured, serialized, protected, transmitted, and verified.

The current implementation is simulation-focused and does not connect directly to a physical drone.

## Current Components

### Telemetry Packet

`telemetry.py` provides a structured telemetry model containing:

- Source identifier
- Timestamp
- Latitude
- Longitude
- Altitude
- Battery level

### Telemetry Serialization

`serializer.py` converts telemetry packets into JSON and reconstructs them from serialized data.

This provides a standard representation suitable for simulated communication.

### Integrity Protection

`integrity.py` provides HMAC-SHA256 signatures for telemetry data.

The integrity layer helps detect whether telemetry has been modified after signing.

It does not provide encryption or confidentiality.

### Secure Telemetry Message

`secure_message.py` combines serialized telemetry with its integrity signature.

The resulting message can be verified before being accepted by another system component.

### Replay Protection

`replay_protection.py` provides timestamp freshness validation.

This establishes a baseline for detecting stale telemetry messages that may represent replayed data.
