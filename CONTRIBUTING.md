# Contributing to Elite Zaki

Thank you for your interest in contributing to Elite Zaki.

Elite Zaki is a long-term research and engineering project exploring Artificial Intelligence, Robotics, Computer Vision, Autonomous Systems, Edge Computing, and Cybersecurity.

Contributions that improve the project's software, research quality, reliability, safety, security, testing, or documentation are welcome.

---

## Areas of Interest

Contributions may include:

- Artificial Intelligence
- Machine Learning
- Computer Vision
- Thermal Image Processing
- Robotics
- Autonomous Navigation
- Sensor Fusion
- Edge Computing
- Networking
- Cybersecurity
- Simulation
- Software Engineering
- Testing
- Documentation
- Performance Optimization

---

## Development Principles

Contributors should prioritize:

1. Safety
2. Security
3. Reliability
4. Reproducibility
5. Maintainable code
6. Clear documentation
7. Responsible AI development

---

## Before Contributing

Please:

1. Read the `README.md`.
2. Review the project architecture.
3. Check existing Issues and Pull Requests.
4. Avoid duplicating existing work.
5. Keep changes focused.
6. Add tests when appropriate.
7. Update documentation when behavior changes.

---

## Code Guidelines

Python code should generally follow:

- Clear naming
- Small, focused functions
- Type hints where appropriate
- Useful comments
- Appropriate error handling
- Testable architecture
- Consistent formatting

Avoid unnecessary complexity.

---

## Pull Requests

A Pull Request should explain:

- What changed
- Why the change was necessary
- How it was tested
- Any known limitations
- Any future work required

For significant architectural changes, discuss the proposed approach before implementation whenever possible.

---

## Testing

New functionality should include appropriate tests whenever practical.

Before submitting a Pull Request, contributors should verify that:

- Existing tests pass
- New tests pass
- No sensitive information is included
- Documentation is updated where necessary

---

## Research Contributions

For experimental work, document:

- Research question
- Hypothesis
- Method
- Dataset or simulation environment
- Parameters
- Evaluation metrics
- Results
- Limitations

Reproducibility is an important part of Elite Zaki's research philosophy.

---

## Security

Do not contribute code designed to:

- Cause physical harm
- Enable unauthorized access
- Bypass security controls
- Conduct unauthorized surveillance
- Circumvent safety mechanisms

For security vulnerabilities, follow the procedures described in `SECURITY.md`.

---

## Responsible Autonomous Systems

Elite Zaki research should prioritize:

- Human oversight
- Safety constraints
- Fail-safe behavior
- Controlled testing
- Simulation before physical deployment
- Privacy
- Responsible AI

Autonomous capabilities should be developed and evaluated within appropriate safety and legal boundaries.
